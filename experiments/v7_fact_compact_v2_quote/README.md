# v7 fact_compact + 역할·적용조건 보정

2026-09-09 주요 CPU 통합 작업 완료 시점의 소스 스냅샷입니다.
루트 기본 구현을 대체하지 않으며 **제출 준비 완료 버전이 아닙니다.**

## 결과와 한계

개발 160건에서 실제 생성한 compact 후보의 응답 480개를 다시 판정했습니다.
Macro F1은 0.6714290069에서 **0.6972199801**, FP/FN은 64/34에서 60/30으로 변했습니다.
같은 개발 자료에서 오탐 4개와 미탐 4개를 회복했으며 새 참조 오류는 없었습니다.

이는 새 GPU 추론이나 독립 미노출 평가가 아닙니다. 공식 리더보드 점수,
최종 통합본의 전체 추론, L40S 1,853건/2시간 충족 여부는 미확인입니다.
이전 compact 실행 시간으로는 시간 제한 초과 위험이 큽니다.
데이터·정답·저장 응답을 공개하지 않으므로 아래 합성 테스트가 개발 점수를 재현하지는 않습니다.

## 보존한 변경

- 자격 절의 번호가 붙은 등록 조건을 다음 절 제목으로 잘못 처리하지 않도록 범위를 보존합니다.
- 모델의 구매 대상 사실과 원문의 자격 조건을 함께 확인하되, 불확실성·예외·입력 누락을 유지합니다.
- 실적 제한의 전체 적용조건 불충족과 일부 근거 부재를 구분합니다.
- 실제 선택한 지방 소액수의 견적 절차를 공고 제목·메타데이터·일치하는 금액으로 확인합니다.

## 합성 테스트

저장소 루트에서 Python 3.12로 실행합니다. GPU·모델·대회 데이터는 필요하지 않습니다.

```bash
python -m unittest discover -s experiments/v7_fact_compact_v2_quote/tests -p "test_*.py"
```

17개 테스트는 자격/제출서류 역할, 선택 조건, 부정·불확실성, 관측 누락,
금액 충돌, 실제/가정 절차, ID 변경의 불변성을 확인합니다.

## 추론 진입점

고정 모델과 승인된 대회 자료를 별도로 갖춘 GPU 환경에서 다음 형태로 실행합니다.
`source/requirements.txt`는 평가 이미지의 기존 패키지를 전제로 하며 설치 목록이 아닙니다.
연구용 고정 의존성은 저장소 루트의 `requirements-gpu.lock`을 참고하세요.

```bash
python experiments/v7_fact_compact_v2_quote/source/script.py \
  --data-dir /path/to/official/data \
  --output-dir /path/to/private/output \
  --model-dir /path/to/fixed/model
```

출력은 비공개로 보관하세요. 위 명령의 전체 실행 시간이나 제출 적합성을 보장하지 않습니다.
`manifest.json`에는 공개 소스 21개의 해시와 집계 결과만 기록합니다.
원래 동결본과 공개 소스는 줄바꿈·파일 끝 공백 정규화를 제외하고 동일하며,
테스트는 공개 디렉터리에 맞춰 import 경로만 정리했습니다.
